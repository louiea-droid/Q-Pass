# TAC Check-in redesign — design + plan

Date: 2026-11-20 · Status: approved by user (mockup) · Visual reference: https://claude.ai/artifact/XrPqKkAebuNruq2gYufh6g (private canvas)

## Why

Make the app simpler and friendlier for church volunteers at the door and for admins, with a clearer visual design (ui-ux-pro-max: church → accessible, welcoming, warm gold + deep blue on white).

## Decisions (user)

1. Approved the mockup direction (sign-in, scanner green/red, combined admin desk).
2. Sign-in heading is just **"Welcome"**.
3. After a red (rejected) scan the scanner **pauses** until the volunteer taps **Next person**. Green scans resume automatically.
4. Names are optional everywhere: with no name, the **ticket number is the headline** ("Ticket 0057"), never "unknown"/"no name" as the big text.

## Design

- Tokens: ground #F6F7FB, surface #FFFFFF, ink #1B1E3C, muted #4A4F6E, line #E4E6EF/#D5D8E6, primary indigo #2E3A87 (hover #1F2866), soft #ECEEF8, gold accent #E2B33C (fills only), ok #146C3A, bad #B42318, warn-note bg #FFF7E0 text #5C4508. Dark mode keeps the same roles with dark values.
- Font: Plus Jakarta Sans (next/font), one family, weights 400–800. Body ≥16 px on phones, controls ≥44 px (primary 56 px).
- Sign-in: logo tile, "Welcome", helper line, name + passcode, "Start checking in", gold note about names being recorded.
- Scanner: header = event chip (select) + avatar initial menu (sign out); line "Scanning as <name>" + live "<n> checked in" (polled 15 s); camera box; result card (green "Welcome! Checked in" / red reason + "Ask for an ID, or call an admin if this looks wrong."); bottom bar "Type a ticket number" (opens input) and, while paused, "Next person".
- Admin nav reduced to: Check-in desk (/admin), Events and QR codes (/admin/events), Open scanner (/scan). /admin/people redirects to /admin.
- Check-in desk (/admin): event title + "Switch event" + "Download list"; arrivals card ("<checkedIn> of <named or total> …" + bar + small counts); "Find a guest" search + filter chips + guest cards (Edit / Check in / Undo, 44 px); right column "At the door now" feed + "Volunteers" counts.
- Events and QR pages: restyled with the same tokens; no behaviour change.
